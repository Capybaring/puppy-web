# iPet · Puppy Market

这是一个面向中文宠物商城的 WordPress 自定义主题，已接入 WooCommerce 商品、分类、搜索、促销商品、购物车和结算入口。

## 本地使用（推荐：Docker，适合 Mac M 系列）

1. 启动 Docker Desktop。
2. 在本目录运行：`./start.sh`。
3. 打开启动脚本最后输出的网站地址，完成 WordPress 初始安装。脚本会自动避开被占用的端口，通常是 [http://localhost:8080](http://localhost:8080)。
4. 在后台「外观 → 主题」启用 Puppy Market。
5. 在「设置 → 阅读」中选择静态首页；如果首页没有显示主题内容，创建一个空白页面并将其设为首页。
6. 安装并启用 WooCommerce。
7. 按下方“后台内容配置”完成 Logo、首页媒体、分类缩略图、页面和菜单设置。

停止站点：`docker compose stop`

重新启动：`docker compose start`

查看日志：`docker compose logs -f wordpress`

当前本地数据库账号仅用于开发，请不要用于生产环境。

## 后台内容配置

- 「外观 → 自定义 → 站点身份」上传 Logo。
- 「外观 → 自定义 → 首页资源」选择三张轮播图、宣传视频、视频封面和护理区域图片。
- 「商品 → 分类」创建分类并上传分类缩略图。主题不会自动创建或重命名分类。
- 为商品上传商品图片和商品相册；无图商品使用 WooCommerce 默认占位图。
- 在「页面」中创建 About、Contact、Shipping、Returns 和 Privacy Policy 等真实页面。
- 在「外观 → 菜单」中配置主菜单以及 Footer Shop、Footer Help、Footer About 三个页脚菜单。
- 在商品品牌分类法或商品标签中维护品牌；主题不再提供写死的示例品牌。
- 首页优惠区会自动读取后台已发布且设置了促销价的商品。
- 商店页、商品详情页、购物车和结算页已经套用 iPet 主题样式。
- 商品主图、库存状态、简单商品快捷加购和可变商品规格选择已接入；支付、物流和会员规则仍需在后台配置。

图片、视频、Logo、商品、分类、页面和菜单均保存在 WordPress 数据库或媒体库中，不放在主题仓库。主题的 `assets` 目录仅保留 JavaScript 等程序资源。

## 当前开发状态

这是本地开发环境。WooCommerce 的 HTTPS 提示属于预期现象；正式上线前需要配置 HTTPS、真实支付账号、物流规则、库存和隐私/退换货页面。

当前产品范围参考 Chewy 的电商信息架构，但已明确排除医疗处方、地区切换、保险、动物服务、公益领养和低频大型动物。保留热门宠物目录、搜索、分类、筛选、商品详情、购物车、结算和账户入口。
